01 / UNDERSTAND

What matters this week

01

Keep comparisons controlled

Use the same problem definition and environment where appropriate. Record changed parameters so an apparent improvement is interpretable.

02

Explain limitations honestly

Show when the method scales poorly and identify plausible reasons. Evidence for one workload or machine is not a universal performance claim.

03

Draft while experiments are fresh

Write the method and result interpretation now. Preserve scripts and data that support the figures in the report.

02 / BUILD

Suggested milestone
