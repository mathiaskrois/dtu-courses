01 / UNDERSTAND

What matters this week

01

Latency dominates small messages

The approximate transfer model T=α+n/β separates startup latency from sustained bandwidth. Many small messages can cost more than one larger transfer.

02

Units matter

Network rates often use bits per second, while measurements use bytes per second. Divide by eight before comparing them, and state whether units are decimal.

03

Node placement changes performance

Ranks on one socket, multiple sockets or different nodes use different communication and memory paths. Record placement alongside timings.

02 / PRACTISE

Estimate communication cost

30–60 min · Suggested

Assume latency α=20 μs and sustained bandwidth β=1 GB/s using decimal units. Estimate the transfer time for 1 kB and 1 MB. Convert a theoretical 10 Gbit/s link rate to GB/s.
