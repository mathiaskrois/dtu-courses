01 / UNDERSTAND

What matters this week

01

Processes avoid one shared interpreter bottleneck

Multiprocessing uses separate Python interpreters. Passing data, starting workers and collecting results still cost time; compiled numerical libraries can have their own threading.

02

Chunk size trades overhead against balance

Small chunks improve flexibility but increase task-management costs. Large chunks reduce overhead but can leave some workers idle.

03

Time the same work fairly

Record what is included: worker startup, input preparation, computation and collection. Compare matching workloads instead of mixing end-to-end and kernel-only timings.

02 / PRACTISE

Check a simple speedup

30–60 min · Suggested

A serial job takes 12 seconds. With four worker processes the computation takes 3 seconds, plus 2 seconds for startup and data transfer. Compute end-to-end speedup and efficiency. What would reporting only computation time hide?
