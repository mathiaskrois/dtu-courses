01 / UNDERSTAND

What matters this week

01

A result needs a reason

Connect the observed scaling curve to workload balance, communication and serial stages. Do not stop at stating which run was faster.

02

Know your own implementation

Be able to trace task distribution, message exchange and result collection. The oral exam asks you to present work and answer questions.

03

Carry a reusable experiment method forward

Preserve input settings, job scripts, module versions and plotting steps so Project 2 does not begin with an unreproducible workflow.
