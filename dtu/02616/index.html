WEEK 02 / 8 SEPTEMBER

Networks & multi-node MPI

Distinguish message-startup cost from transfer cost.

Open week 2 page ↗Week page ↗
01

Understand

The essential ideas
  1. Latency dominates small messages

    The approximate transfer model T=α+n/β separates startup latency from sustained bandwidth.

  2. Units matter

    Network rates often use bits per second, while measurements use bytes per second.

  3. Node placement changes performance

    Ranks on one socket, multiple sockets or different nodes use different communication and memory paths.

mpi4py communication

Open week 4 page ↗Week page ↗
01

Understand

The essential ideas
  1. Objects and buffers have different paths

  3. Collectives have coordinated roles

    Bcast, Gather and Reduce express different patterns.

WEEK 09 / 3 NOVEMBER

Parallel I/O

Treat reading and writing as part of the performance story.

Open week 9 page ↗Week page ↗
01

Understand

The essential ideas
  1. I/O can dominate the workflow

    A faster compute kernel has limited value when input or output controls end-to-end time.

  2. Each rank needs a clear data region

    Concurrent writes require non-overlapping ownership or a coordinated I/O scheme.

  3. File-system behaviour matters

    Many tiny files, metadata traffic and simultaneous access can change performance.
