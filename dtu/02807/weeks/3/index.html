01 / UNDERSTAND

What matters this week

01

Map and reduce have different jobs

The mapper emits keyed intermediate records. Records are grouped by key before a reducer aggregates them; trace these stages separately when debugging.

02

Communication and skew matter

Distributed work has overhead. A reducer receiving one enormous key group can become a bottleneck even when most keys are well balanced.

03

Use distribution when the problem warrants it

The project brief specifically warns against MapReduce without a meaningful use for parallelism. A local map/reduce exercise teaches the pattern; it does not demonstrate cluster-scale performance.

02 / PRACTISE

Trace word count and an inverted index

30–60 min · Suggested

Use document 0: “red blue red” and document 1: “blue green”. Write mapper outputs, grouped values, final counts and an inverted index of term → document IDs.
