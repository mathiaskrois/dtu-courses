Topics

A baseline anchors the comparison

Use a simple method that answers the same question on the same data. It gives meaning to improvements or disappointments.

Keep the pipeline reproducible

Run data preparation, modelling and evaluation in a fixed sequence. Record parameters and assumptions, including randomness where relevant.

Measure more than one convenient output

Evaluation must establish whether the approach works for the actual problem. Consider runtime or resource cost alongside quality where relevant.
