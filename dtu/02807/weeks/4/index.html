Topics

Jaccard compares sets

Jaccard similarity is intersection size divided by union size. Document shingling, deduplication and preprocessing determine what the sets actually represent.

Minhash estimates Jaccard similarity

Matching signature entries estimate a set similarity when hash/permutation assumptions hold. Smaller signatures trade accuracy for storage and computation.

LSH produces candidates, not final matches

Banding changes the probability that a pair is considered. Verify candidate similarities exactly and measure false positives and missed matches against an appropriate baseline.
