Topics

Use arrays for numerical work

NumPy arrays support vectorised operations and linear algebra. Check shapes and units instead of assuming that a function call implies a sensible result.

Use Pandas to make data preparation explicit

Inspect types, missing values and duplicates before aggregating. A clear preparation step makes later results interpretable and repeatable.

A notebook should run from a clean start

Separate setup, inputs, transformations and outputs. The final project includes a documented Jupyter Notebook, so a reproducible notebook now prevents packaging problems later.

Solve a small system and draft a data summary
