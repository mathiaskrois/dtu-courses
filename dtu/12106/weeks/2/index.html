Topics

Compare the same service

The functional unit quantifies what the system delivers. Comparing one chip with one different chip is misleading if their performance, lifetime or service differs. Define the function before choosing quantities.

Boundaries determine what you leave out

Map raw materials, manufacturing, use and end of life. State exclusions so that the comparison remains interpretable; a manufacturing-only result is not automatically a whole-life result.

Use a tiered assessment

Start with screening and increase detail where it changes the decision. Data requirements grow with assessment depth, so prioritise likely hotspots instead of collecting every possible measurement.
