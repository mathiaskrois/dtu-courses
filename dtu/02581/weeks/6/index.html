Distance fields & isosurfaces

Do the task ↓Open this week in Learn ↗ (opens a new tab)
← Week 5Week 6 of 13Week 7 →

Topics

The surface is a level set

An implicit surface consists of points where f(x)=c. A signed distance field additionally measures distance with a chosen inside/outside sign.

Crossings need interpolation

A sign change across an edge indicates a zero crossing for a continuous field. Interpolate sampled values rather than always using the midpoint.

Resolution limits detail

A coarse grid can miss thin features or create ambiguity. Inspect topology as well as appearance in the reconstructed mesh.

Locate two zero crossings

Optional practice

Use linear interpolation on a unit edge. First, endpoint values are −1 and 3; second, −2 and 2. Find t from the first endpoint where f=0. What does a coarse grid risk missing?
